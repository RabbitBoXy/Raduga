# 🌈 Raduga

**Русское ядро для Minecraft сервера на основе Paper 26.1.2**

## ✨ Особенности
- ✅ Частичный перевод консоли на русский язык
- ✅ Русские сообщения о входе/выходе игроков
- ✅ Убрана реклама Paper
- ✅ 100% совместимость с плагинами Bukkit/Spigot/Paper

## 📥 Скачать готовый сервер
Перейди в раздел [Releases](../../releases)
